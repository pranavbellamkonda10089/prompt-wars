## 🌟 Overview

**ReelMind AI** is an intelligent recommendation agent that bridges students' casual short-form video consumption (Instagram Reels, YouTube Shorts, TikTok) into structured, high-value technical learning pathways.

Traditional recommendation algorithms rely on **shallow keyword matching** or viral clickbait affinity. ReelMind AI looks beneath the surface, deducing latent computer science and engineering curiosity to deliver rigorous, hype-free educational progression.

## 🎯 The Core Directive: Solving "The Built-in Trap"

### What is The Built-in Trap?
When a student interacts with casual content (e.g., *Java NullPointer Meme*, *Day in the Life of a FAANG SWE*, *MacBook Pro Spec Review*):
- **Naive Keyword Matcher Fails:** Recommends elementary syntax loops (`Java For-Loops 101`) or viral clickbait (`10 AI Tools to Get a $200k Job in 30 Days`). This produces user churn and stagnation.
- **ReelMind AI Succeeds:** Infers the deeper latent intent—**"Aspiring Software Engineer interested in JVM internals and systems architecture"**—and recommends foundational content (`JVM Memory Architecture & High-Performance GC Internals` or `Consistent Hashing in Distributed Systems`).

| Evaluation Dimension | Naive Keyword Recommender | ReelMind Cognitive Agent |
| :--- | :--- | :--- |
| **Signal Ingestion** | Single token keyword matching | Multi-reel interaction pattern synthesis |
| **Trap Handling** | **FAILS TRAP** (Serves basic syntax loops) | **TRAP OVERCOME** (Infers latent engineering curiosity) |
| **Anti-Hype Filter** | Vulnerable to affiliate fluff & listicles | **100% Fluff-Free** curriculum verification |
| **Output Compliance** | Unstructured / Inconsistent | **Exact 8-Key Standardized Contract** |

## 📋 Strict 8-Key Output Schema Specification

Every recommendation generated by ReelMind AI strictly conforms to the following standardized contract:

```yaml
CURRENT REEL: [Reference to currently focused reel]
INTEREST DETECTED: [Inferred latent computer science / career focus]
WHY: [Concise evidence from interaction history, avoiding superficial tokens]
RECOMMENDED TECH REEL: [Title of high-signal, non-clickbait technical video]
CATEGORY: [AI | DSA | Java | HLD | Cybersecurity | Cloud | Hardware | Career | Other]
WHY THIS RECOMMENDATION: [Pedagogical connection bridging casual browsing to serious learning]
DIFFICULTY: [Beginner | Intermediate | Advanced]
CONFIDENCE: [High | Medium | Low]
```

## 🚀 Key Features

1. **📱 Interactive Reels Player (Simulated Mobile Device)**:
   - Full Instagram-style gesture simulation (play/pause, double-tap heart bursts, dynamic comments, volume control).
   - 60 FPS procedural canvas backgrounds tailored to each technical domain.
   - Dynamic insertion of AI-generated reels based on live recommendations.

2. **📊 Live AI Reasoning & Co-Pilot Split View**:
   - Real-time 6-phase Chain of Thought (CoT) step inspection with JSON payloads.
   - Latent affinity vector distribution (0–100%).
   - Anti-hype depth score verification.

3. **🔬 Trap Comparison Benchmark Matrix**:
   - Interactive modal demonstrating side-by-side behavioral divergence between naive keyword matchers and ReelMind AI.

4. **✨ Instant 1-Click Contract Copy**:
   - Copy formatted 8-key text or structured JSON for evaluation verification.

## 🛠️ Architecture & Tech Stack

- **Framework**: React 18 with TypeScript (Strict Mode)
- **Bundler & Tooling**: Vite 6, Vitest, ESLint, Prettier, PostCSS, Tailwind CSS
- **AI / LLM Integration**: `@google/generative-ai` (Gemini Flash & Pro) with deterministic high-signal fallback
- **State Management**: Reactive React hooks (`useCallback`, `useMemo`, `useRef`) with zero unnecessary re-renders
- **Accessibility**: WCAG 2.1 AA Compliant (ARIA roles, keyboard trap support, focus indicators, screen reader labels)
- **Testing**: 100% test suite pass rate with Vitest & Testing Library

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment (Optional for Live Gemini API)
Create a `.env` file in the root directory:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```
*(Note: ReelMind AI runs seamlessly with its built-in cognitive engine even without an API key).*

### 3. Start Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
